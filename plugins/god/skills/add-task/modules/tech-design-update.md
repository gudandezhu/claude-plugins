# tech-design.md 更新策略

> 本文档由 SKILL.md Step 3 引用。定义如何安全更新 tech-design.md。

## 核心原则

1. **只在末尾追加**：所有新增内容追加到 tech-design.md 文件末尾，禁止在已有章节中插入或修改
2. **保护已有锚点**：已有章节的标题、编号、正文均不可变动，其他任务依赖这些锚点引用
3. **标记可追溯**：所有新增内容用 HTML 注释标记包裹

## 标记格式

```html
<!-- ADD-TASK:{日期}:{任务ID}:START reason="{补充原因}" -->
...新增内容...
<!-- ADD-TASK:{日期}:{任务ID}:END -->
```

示例：
```html
<!-- ADD-TASK:2026-04-15:BE-05:START reason="缺少供应商状态变更接口" -->
## 补充：供应商状态变更接口

### 接口定义
| POST | /api/v1/suppliers/{id}/status | xxx-service | 供应商状态变更 |

### 处理流程
...
<!-- ADD-TASK:2026-04-15:BE-05:END -->
```

## 操作步骤

### 1. 读取现有结构

读取 tech-design.md 全文，了解已有章节结构，确认新增内容不与已有内容重复。

### 2. 在文件末尾追加

在 tech-design.md 末尾追加新章节，用标记包裹。新章节标题使用"补充：{功能描述}"格式。

## 验证

- [ ] 所有 `<!-- ADD-TASK:...:START -->` 都有对应的 `<!-- ADD-TASK:...:END -->`
- [ ] 标记中的任务 ID 与实际新增的任务 ID 一致
- [ ] 原有内容未被修改或删除（diff 中无已有行的变更）
