# 通用 PRD 类型

按场景→模块映射表动态选配模块，无额外差异约束。

## 适用场景

- 新功能开发
- 功能优化/重构
- 流程改造
- 数据报表/看板

## 模块要求

按 SKILL.md 场景→模块映射表动态选配模块。

## 重点关注

- M02（需求背景与目标）：现状-目标-差距三段式完整
- M07（业务流程）：节点说明含业务规则，聚焦数据流转
- M09（功能详细说明）：每个功能标注改动类型，聚焦业务规则
- M11（异常与边界）：四维度覆盖
- M03b（验收标准详细）：E2E 与流程图一一对应
