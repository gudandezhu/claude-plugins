## 📸 验收证据要求

### 必须采集的证据
1. **请求截图** - 包含请求URL、请求方法、请求参数
2. **响应截图** - 包含响应状态码、响应数据
3. **日志截图** - 包含接口调用日志（可选）

### 证据存储路径
```
evidence/[版本号]/api/[模块名]/
├── [接口名1]/
```

## 📖 使用说明

### 填写步骤
1. **填写文档信息** - 在文档开头填写模块名称、负责人、编写人等信息
2. **填写API接口清单** - 列出所有需要测试的API接口
3. **编写测试用例** - 按照模板格式编写每个测试用例
4. **执行测试** - 按照测试用例执行测试
5. **记录结果** - 填写实际结果和状态
6. **采集证据** - 上传验收证据截图

### 命名规范
- **用例ID格式**：`API-{模块编号}-{用例编号}`
  - 模块编号：AUTH（认证）、TASK（任务）、USER（用户）、RULE（规则）等
  - 用例编号：正常 001-099，异常 E01-E99，边界 B01-B99
  - 示例：API-AUTH-001、API-AUTH-001-E01、API-RULE-001-B01

### 优先级定义
- **P0** - 核心功能，必须测试
- **P1** - 重要功能，推荐测试
- **P2** - 一般功能，可选测试
