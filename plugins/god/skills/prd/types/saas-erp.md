# SaaS ERP 类型

基于 SKILL.md 核心层，增加多租户约束和业务域划分。

## 适用场景

- SaaS ERP 平台功能开发
- 多租户系统的新增/修改功能
- 涉及跨模块业务域的需求

## 差异规则

### 多租户必审

M12（权限与敏感信息）**必须**包含租户隔离说明（仅当 M12 被激活时生效）：

- **数据隔离**：每个功能说明需标注数据是否按租户隔离，隔离方式（共享表+租户ID / 独立表 / 独立库）
- **权限隔离**：角色权限矩阵需覆盖租户管理员 vs 平台管理员
- **配置隔离**：系统配置项需标注是租户级还是平台级

### 模块按业务域划分

PRD 的功能说明（M09）按业务域组织，每个功能标注所属域（仅当 M09 被激活时生效）：

| 域 | 覆盖范围 |
|----|---------|
| SKU | 商品/价格/分类/品牌 |
| 进销存 | 采购/销售/库存/供应商 |
| MES | 生产制造/工艺/工单 |
| 项目 | 项目管理/任务/里程碑 |
| 财务 | 应收/应付/对账/结算 |
| 文件 | 文件中心/文档管理 |
| 租户 | 租户管理/企业设置/账号 |
| CMS | 内容管理/消息通知 |

跨域功能需在 M10（关联与影响）中标注涉及的所有域及联动方式（仅当 M10 被激活时生效）。

## 模块要求

按 SKILL.md 场景→模块映射表动态选配模块，加上述多租户差异约束（仅在被激活的模块上生效）。

## 重点关注

- M02（需求背景与目标）：现状-目标-差距三段式完整
- M10（关联与影响）：标注涉及的业务域和跨域联动
- M09（功能详细说明）：按业务域组织，标注租户隔离方式
- M12（权限与敏感信息）：必须包含租户隔离说明
