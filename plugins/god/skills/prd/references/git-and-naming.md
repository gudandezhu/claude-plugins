# Git 协同与文件命名

## Git 协同规则

涉及文件变更时自动遵守：

### 强制规则

1. **产出前**：`git pull` 拉取最新代码
2. **产出后**：`git add` → `git commit` (commit规范必须为 #0000开头,后续内容大于6字符)→ `git push`
3. **纯探索/问答**：不触发Git操作
4. **分支策略**：日常小任务在main分支，大型任务创建feat/分支

### 提交信息格式

```
类型: 项目前缀-问题ID 描述
```

| 类型 | 使用场景 | 示例 |
|------|----------|------|
| feat | 新增文档或功能 | `#0000 feat: PRJ-0001 新增采购入库PRD v1.0` |
| fix | 修改已有内容 | `#0000 fix: PRJ-0002 修复表单字段缺失` |
| docs | 更新知识库或规范 | `#0000 docs: PRJ-0003 更新业务知识库-权限模块` |

> 项目前缀（如 `PMKB`、`PRJ`）在项目 CLAUDE.md 中定义。

## 文件命名规则

创建任何文件时自动遵守：

| 类型 | 格式 | 示例 |
|------|------|------|
| PRD文件 | `[功能名称]-PRD-v[版本号].md` | `用户权限管理-PRD-v1.0.md` |
| 任务文件 | `YYYY-MM-DD_任务名称.md` | `2026-04-20_付费权益展示.md` |
| 教程文件 | `序号_教程名称.md` | `01_创建新任务教程.md` |
| 过程记录 | `YYYY-MM-DD_标签-简述.md` | `2026-04-24_规范缺失-评审清单未覆盖移动端.md` |
| 目录名 | 中文，用连字符分隔 | `用户权限管理/` |
| 版本号 | `v[主版本].[次版本]` | v1.0、v1.1、v2.0 |
| 通用规则 | 中文描述、连字符分隔、无特殊字符、无空格 | - |
