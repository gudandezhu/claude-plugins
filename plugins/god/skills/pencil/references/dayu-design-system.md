## 5. 表格规范

> **⛔ 强制规则**：所有列表页表格的列宽之和必须严格等于 1112px。这是最常见的原型质量问题——列宽总和不足导致表格右侧大量空白。每次创建或修改表格后，必须验证列宽总和。

### 5.1 表头规范
- **背景色**：#FAFAFA
- **文字颜色**：#202D40
- **字体**：系统字体, 14px, 600字重
- **内边距**：[14, 20]
- **边框**：底部 1px #DCDFE6

### 5.2 表格行规范
- **背景色**：#FFFFFF
- **内边距**：[16, 20]
- **边框**：底部 1px #DCDFE6
- **对齐方式**：水平分布（justifyContent: space_between）

### 5.3 表格内容规范
- **主要内容**：系统字体, 14px, 400字重, #303133
- **次要内容**：系统字体, 14px, 400字重, #606266

### 5.4 列宽分配原则

#### 5.4.1 总宽度计算
- **容器宽度**：1152px（标准内容区域）
- **容器内边距**：左右各 20px，共 40px
- **可用宽度**：1112px（1152px - 40px）
- **所有列宽度之和必须等于 1112px**

#### 5.4.2 列宽均衡原则 ⚠️ 重要

**❌ 错误做法**：
- 单列宽度超过 300px（除非是唯一的内容列）
- 使用 `fill_container` 导致某列占据过多剩余空间
- 列宽分配不均衡，导致视觉上有明显的宽窄差异

**✅ 正确做法**：
- 根据内容特点合理分配列宽
- 避免单列过宽，保持视觉平衡
- 优先使用固定宽度，谨慎使用 `fill_container`
- 所有列宽度之和 = 1112px

#### 5.4.5 使用 fill_container 的注意事项

**⚠️ 警告**：`fill_container` 会占据所有剩余空间，容易导致列宽不均衡。

**使用场景**：
- ✅ 仅当该列是唯一需要自适应的内容列时使用
- ✅ 其他列都是固定宽度，且总和已知
- ✅ 该列的内容长度不确定，需要自适应

**禁止场景**：
- ❌ 多个列同时使用 `fill_container`
- ❌ 该列会导致宽度超过 300px
- ❌ 不清楚剩余空间大小时使用

**替代方案**：
- 优先计算并使用固定宽度
- 使用上述参考宽度进行分配
- 确保所有列宽度之和 = 1112px

## 13. 使用说明

### 13.1 设计新页面时
1. 选择合适的页面模板（列表页/表单页/详情页）
2. 参考本规范配置搜索区域
3. 参考本规范配置操作区域
4. 参考本规范配置表格/表单
5. 使用设计检查清单验证
6. 截图确认视觉效果

### 13.2 颜色使用原则
- 主色（蓝色）用于主要操作和强调
- 红色仅用于危险操作和错误状态
- 绿色用于成功和正常状态
- 橙色/黄色用于警告和中等级别
- 灰色用于次要信息和禁用状态

### 13.3 一致性原则
- 同类元素使用相同样式
- 同类操作使用相同颜色
- 同类状态使用相同徽章样式
- 保持间距、圆角、字体的一致性

## 14. 表单设计规范

### 14.1 表单区域标题

#### 14.1.1 设计原则
表单应使用区域标题来划分不同的信息组，提升表单的可读性和结构清晰度。

#### 14.1.2 样式规范
- **字体**：系统字体
- **字号**：16px
- **字重**：600（Semibold）
- **颜色**：#303133（深灰色）
- **位置**：作为区域的第一个子元素
- **间距**：与下方字段保持16px间距（通过父容器的gap属性控制）

#### 14.1.3 标准命名
- 基本信息区域：使用"基本信息"
- 扩展信息区域：使用"扩展信息"
- 其他自定义区域：根据业务语义命名

#### 14.1.4 代码示例（.pen 格式）
```javascript
{
  type: "text",
  content: "基本信息",
  fill: "#374151",
  fontFamily: "Inter",
  fontSize: 16,
  fontWeight: "600",
  name: "sectionTitle"
}
```

#### 14.1.5 使用场景
- ✅ 所有基于 VEdnN 模板的表单页面
- ✅ 包含多个信息分组的表单
- ✅ 需要明确区分不同类型信息的场景
- ❌ 单一区域的简单表单（可选）

#### 14.1.6 设计考量

**字体大小层次**：
- 区域标题：16px（建立视觉层次，突出区域划分）
- 字段标签：14px（保持信息密度）
- 差异：2px，足够区分但不会过于突兀

**颜色层次**：
- 区域标题：#303133（深灰色，柔和但清晰）
- 字段标签：#606266（常规文字色）
- 差异：标题稍浅，避免视觉竞争

**字重层次**：
- 区域标题：600（Semibold，强调区域分组）
- 字段标签：500（Medium，保持清晰但不抢眼）
- 差异：标题更粗，增强层次感

#### 14.1.7 实施说明

**模板层面**：
- 基础表单模板（VEdnN）已在设计系统层面添加区域标题
- 所有未来基于此模板创建的表单实例将自动包含标题

**现有表单迁移**：
- 已有表单实例需要手动添加区域标题以保持一致性
- 使用 Insert + Move 操作将标题添加到区域的第一个位置

**技术实现**：
```javascript
// 在区域中插入标题
title=I("regionId", {
  type: "text",
  content: "区域标题",
  fill: "#374151",
  fontFamily: "Inter",
  fontSize: 16,
  fontWeight: "600",
  name: "sectionTitle"
})

// 将标题移动到第一个位置
M(title, "regionId", 0)
```

## 15. 页面样式强制规范 ⚠️ 必须遵守

> 以下规范基于 SLA 管理系统开发实践总结，适用于所有基于大禹设计系统的页面。违反这些规范会导致页面样式不一致，需要反复修复。

### 15.1 列表页样式规范

#### 15.1.1 主内容区域

| 属性 | 值 | 说明 |
|------|-----|------|
| fill | `#FFFFFF` | 白色背景，不使用灰色 |
| height | `fill_container(852)` | 撑满页面（MtsyV 布局下，900 - 48 header = 852） |
| layout | `vertical` | 垂直布局 |
| gap | `16` | 子元素间距 |
| padding | `24` | 内边距 |

父容器 `MtsyV` 的 fill 也必须设为 `#FFFFFF`。

#### 15.1.2 搜索栏

#### 15.1.3 表格

| 属性 | 值 | 说明 |
|------|-----|------|
| cornerRadius | `0` | 无圆角 |
| stroke | 无 | 无外层边框 |
| height | `fill_container` | 撑满剩余空间，把分页器推到底部 |
| clip | `true` | 裁剪溢出内容 |

保留表头底部分隔线和行间分隔线（`stroke: { fill: "#DCDFE6", thickness: { bottom: 1 } }`）。

#### 15.1.4 分页器

| 属性 | 值 | 说明 |
|------|-----|------|
| cornerRadius | `0` | 无圆角 |
| stroke | 无 | 无边框，无分隔线 |
| 位置 | 页面底部 | 通过表格 fill_container 实现 |

#### 15.1.5 列表详情下钻与操作列

**详情下钻规范（强制）**：
- 查看列表详情统一通过**名称字段点击下钻**到详情页
- 名称字段使用蓝色链接样式（#409EFF），点击跳转详情页
- **禁止**在操作列放"查看"/"详情"等读操作按钮

**操作列规范**：
- 操作列仅放**写操作**按钮：
  - **编辑**：蓝色文字链接，跳转到编辑表单
  - **删除**：红色文字链接，弹出删除确认
- 如果列表页没有编辑/删除等写操作，则不需要操作列

### 15.2 详情页/表单页卡片样式规范

信息区块（基本信息、扩展信息等）必须包含完整卡片样式：

| 属性 | 值 | 说明 |
|------|-----|------|
| fill | `#FFFFFF` | 白色背景 |
| cornerRadius | `4` | 圆角 |
| padding | `20` | 内边距 |
| stroke | `{ fill: "#DCDFE6", thickness: 1 }` | 浅灰边框 |
| layout | `vertical` | 垂直布局 |
| gap | `16` | 子元素间距 |
| width | `fill_container` | 撑满父容器 |

**⚠️ 使用 R() 替换节点时必须手动添加这些属性，不会自动继承！**

### 15.3 侧边栏规范

| 规则 | 说明 |
|------|------|
| 菜单一致性 | 所有页面（列表页/详情页/表单页）的侧边栏菜单必须完全一致 |
| 高度 | `fill_container(900)` — 在绝对定位布局中必须提供回退值 |
| 侧边栏宽度 | `200px` |
| 侧边栏背景 | `#2E363F` |
| 当前页高亮文字 | 当前页面对应的菜单项文字色设为 `#FB9100`（橙色） |
| 当前页高亮背景 | 当前页面对应的菜单项 fill 设为 `#40536F` |
| 其他菜单项 | fill 设为 `#00000000`（透明），文字色 `#EEF1F6` |

**⚠️ 详情页模板（yAaL5）和表单模板（VEdnN）的侧边栏菜单与列表页模板（MtsyV）不同，复制后必须替换侧边栏菜单！**

### 15.4 表格列处理规范

从其他列表页复制表格后，多余列的处理方式：

| 方式 | 是否正确 | 原因 |
|------|---------|------|
| `D("nodeId")` 删除节点 | ✅ 正确 | 节点彻底移除 |
| `enabled: false` | ❌ 错误 | 仍参与 space_between 布局 |
| `width: 0` | ❌ 错误 | 仍占据布局位置 |

### 15.5 页面关联完整性规范

每个功能模块必须检查以下关联页面是否齐全：

| 列表页操作 | 必须有的关联页面 |
|-----------|----------------|
| "新增"按钮 | 新增表单页 或 新增弹窗（Modal） |
| "编辑"操作 | 编辑表单页（通常复用新增表单） |
| "删除"操作 | 删除确认弹窗（Popconfirm Danger） |
| "查看"操作 | 详情页 |

**检查方法**：创建完列表页后，立即检查操作列中的每个操作是否有对应的目标页面。
