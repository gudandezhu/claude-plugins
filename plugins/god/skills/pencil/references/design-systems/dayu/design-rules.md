# 大禹平台设计规范 - 页面布局与交互规范

> 本文档基于大禹平台实际页面验证（2026-04-10），作为 PRD 原型设计的强制规范。

## 1. 列表页标准布局

大禹平台所有列表页遵循统一的四层布局结构：

```
┌─────────────────────────────────────────────────┐
│ 面包屑导航：监控配置 / 通知策略                      │
├─────────────────────────────────────────────────┤
│ 筛选条件行（可多行）          [查询] [重置]          │
├─────────────────────────────────────────────────┤
│ 常用功能：[+ 新增] [批量禁用] [批量启用]             │
├─────────────────────────────────────────────────┤
│ 表格（表头 + 数据行）                               │
├─────────────────────────────────────────────────┤
│ 分页器（居中）                                      │
└─────────────────────────────────────────────────┘
```

### 1.1 筛选条件行

- 标签 + 控件水平排列，多个筛选项在同一行
- 筛选项过多时可分多行（如活跃告警页3行）
- 查询按钮（蓝色主按钮）和重置按钮（次按钮）放在筛选条件最后一行的右侧
- 部分页面有"更多"折叠图标（如告警规则页）

### 1.2 常用功能行

- 位于筛选条件下方，表格上方
- 以"常用功能："标签开头，后跟操作按钮
- **"+ 新增"按钮放在这里，不在筛选条件行**
- 批量操作按钮（批量禁用/批量启用）也放在这里
- 新增按钮为蓝色主按钮，批量禁用为红色，批量启用为绿色
- 对应大禹组件库：List Action Bar（dayu:1VBoa）
- **例外**：活跃告警、告警历史等系统自动生成数据的页面无"常用功能"行

### 1.3 表格

- 表头行：灰色背景（#FAFAFA），字体12px，颜色 #7A7A7A，加粗
- 数据行：白色背景，字体12px，颜色 #0D0D0D，行高42px
- 行底部分割线：#E5E7EB
- 每个单元格用 frame 包裹，设置固定宽度和 padding [0, 8]
- 名称字段为蓝色链接（#1890FF），点击下钻到详情/编辑页
- 状态字段使用彩色标签（启用=蓝色，禁用=红色）
- **不在操作列设置"详情/查看"按钮**，通过名称字段点击下钻

### 1.4 分页器

- 位于表格下方，居中显示
- 标准结构：共N条 | 页码按钮 | 每页条数选择（默认40条/页）| 前往N页
- 对应大禹组件库：Pagination Full（dayu:cDHCZ）

### 1.5 操作列

- 操作按钮为蓝色文字链接，非按钮样式
- 常见操作：编辑、克隆、删除、启用/禁用、更多
- 删除为红色文字
- 操作之间用间距分隔（gap: 12px）

## 2. 表单页标准布局

### 2.1 多卡片分区

表单页内容按功能分区，每个分区为独立卡片：
- 卡片：白色背景，圆角8px，边框 #E5E7EB，内边距20px
- 卡片标题：16px，加粗，#0D0D0D
- 卡片之间间距10px
- 参考：工单分配规则页（基础信息 / 包含条件 / 排除条件 / 工单处理人）

### 2.2 表单字段

- 标签右对齐，固定宽度（通常80px）
- 标签与控件间距20px
- 必填字段标签前有红色 * 号
- 输入框高度36px，圆角4px，边框 #D1D5DB
- 下拉框右侧有 chevron-down 图标

### 2.3 操作按钮

- 保存（蓝色主按钮）和返回/取消（次按钮）放在页面右上角
- 不在表单底部重复放置

## 3. 条件配置器

参照工单分配规则的"包含条件"交互模式：

### 3.1 条件组模式（工单分配规则）

- 点击"+ 新增"弹出"新建条件组"弹窗
- 弹窗内为表格式条件编辑：值来源 | 参数名 | 运算符 | 期望值 | 操作
- 条件组之间为 OR 关系，条件组内部为 AND 关系
- 每个条件组有备注字段

### 3.2 简化条件模式（升级方案匹配条件）

- 不需要条件组（无 OR 分组），直接内嵌表格
- 表格列：值来源 | 运算符 | 期望值 | 操作（删除）
- 所有条件之间为 AND 关系
- 表格上方显示"+ 新增"按钮和说明文字

## 4. 侧边栏菜单

- 暗色背景（#2E363F），宽度200px
- 菜单项高度40px，左侧内边距48px（子菜单）
- 当前选中项：蓝色背景（#1890FF），白色文字
- 未选中项：半透明白色文字（#FFFFFFA6）
- 菜单分组标题：白色文字，带图标

## 5. 面包屑导航

- 位于页面顶部，侧边栏右侧
- 格式：一级菜单 / 二级菜单 / 当前页面
- 分隔符为 /
- 可点击的层级为蓝色链接

| 卡片标题 | 16px, 600 |

| 表单标签 | 14px, normal |

| 说明文字 | 12-13px |
